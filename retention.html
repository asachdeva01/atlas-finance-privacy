Atlas Finance — Data Retention and Disposal Policy

Registered with Plaid as “Atlas Core Finance”. Effective September 16, 2026. Reviewed every 12 months, or sooner when the app's data handling changes.

1. Scope

This policy covers every category of data the app stores about a user, including data obtained from financial institutions through Plaid (read-only Transactions, Investments, and Liabilities) and through Robinhood's read-only API.

3. Disposal

  • Disconnecting an institution calls Plaid's item removal endpoint so Plaid revokes access on its side, then deletes the stored token, the accounts, and every balance, holding, transaction, and liability that came from that institution. This is one operation and is not reversible.
  • Deleting an account removes every row belonging to that user. Database constraints cascade, so no orphaned data remains.
  • Backups are encrypted and expire automatically after 30 days, so deleted data leaves backups within that window.
  • Storage media: the server disk is fully encrypted (FileVault). Decommissioned media is cryptographically erased.

4. Requests

A user can ask to see, export, or delete their data at any time; requests are completed within 7 days. Contact: a.sachdeva2021@gmail.com.

5. Minimization

The app requests only the three read-only Plaid products it uses and never stores bank credentials. No data is sold, shared, or used for any purpose other than showing the user their own finances.
